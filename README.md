## Descripción del Proyecto
Desarrollo de tres aplicaciones web interactivas inspiradas en la obra *Alicia en el país de las maravillas*, utilizando formularios HTML5, estilos CSS3 personalizados y JavaScript nativo. El proyecto fortalece las estructuras secuenciales, condicionales (`if/else`), de selección múltiple (`switch`), repetitivas (`for`), eventos del DOM y validación de entradas.

### Ejercicios Incluidos:
1. **La poción mágica de Alicia:** Calcula la nueva altura de Alicia según la cantidad de poción consumida y evalúa si puede atravesar una puerta fija de 150 cm.
2. **La merienda del Sombrerero Loco:** Calcula el costo total de una orden de bebidas utilizando un `switch`, aplicando un descuento automático del 10% si se superan las 5 tazas.
3. **El desafío de la Reina de Corazones:** Analiza una secuencia de cartas hasta un límite ingresado por el usuario usando un bucle `for`, clasificando los números en pares e impares, sumándolos y determinando qué grupo tiene mayor acumulación.

## Tecnologías Utilizadas
* **HTML5:** Estructura semántica, controles de formulario y elementos de navegación (`<nav>`).
* **CSS3:** Estilos visuales personalizados inspirados en la obra (sin frameworks ni Flexbox/Grid).
* **JavaScript (Nativo):** Manipulación del DOM (`getElementById`, `value`, `textContent`), eventos (`addEventListener`, `preventDefault`) y validaciones.
